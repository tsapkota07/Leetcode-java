# Data Structures

When to use each and why.

**arrays-strings.txt**
Static size, fast index access. Insertion/deletion cost shifting.

**hashmap-hashset.txt**
HashMap: O(1) lookups. HashSet: membership checks.

**stack-queue.txt**
Stack for LIFO. Queue for FIFO. Order-dependent problems.

**linked-list.txt**
Dynamic size, slow indexing, fast insertion at known position.

**trees.txt**
Hierarchical. DFS/BFS traversal. Balance for fast search.

**heaps.txt**
Min/max heap. Priority extraction. Top-K problems.

**graphs.txt**
Nodes + edges. Connectivity, traversal, shortest path, cycles.

**trie.txt**
Prefix tree. Fast search and autocomplete.
